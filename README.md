# Apache HTML Docker com Docker Compose 🚀

Este é um projeto básico que executa uma aplicação HTML simples utilizando o **Apache HTTP Server** dentro de um contêiner Docker, orquestrado pelo **Docker Compose**.

## 📁 Estrutura do Projeto

```
apache-html-docker/
├── docker-compose.yml
├── html/
│ └── index.html
└── .gitignore
```

## 🚀 Como executar o projeto

> **Pré-requisitos:** Docker Desktop com WSL2 e Docker Compose instalados.

**1. Clone o repositório:**

git clone https://github.com/Rody-CS/apache-html-docker.git
cd apache-html-docker


**2. Suba o container com Docker Compose:**

docker-compose up

**3. Acesse no navegador:**

http://localhost:8080

## 🛠 Tecnologias utilizadas

- Docker  
- Docker Compose  
- Apache HTTP Server  
- HTML5
